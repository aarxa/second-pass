# Sketches

Drop drawings here (PNG or JPEG). Each becomes a benchmark case named `s-<file name>`.
An optional text file with the same name adds notes, e.g. `sun.png` + `sun.txt` containing
"make the rays rotate slowly".

Aim for about 20, from very rough to fairly detailed: simple shapes, a scene, a pattern, a
character. Rough phone photos of paper sketches are fine; that is part of what is being tested.
